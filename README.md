# Blog-posting-site-in-React-JS
you can simply post your thoughts and blogs with peoples connected with this application.

this project is in ReactJS you must install its dependencies and also NodeJS. You can either create an account or just can log in with your personal Gmail account. You can also locally run this project. For this, you have to change the package.json file from the project folder. You can simply disable the sharing and comments from your post.

# To run this project, you have NodeJS Installed on your laptop or desktop and use browser such as Google Chrome, brave, safari, Mozilla Firefox.

# For Manual Installation,

1. Extract Main Project Folder to any directory
2. Set path to your project directory from cmd
3. Enter the command “npm install”
4. After completing it enter the command “npm start”
5. Now, You’ll get a localhost:portnumber, and go to that URL
